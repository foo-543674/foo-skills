AI の応答を読み、次をすべて満たせば合格:

- `package.json` への変更を、ファイル単位でまとめて「承認が要る」にしていない。依存の一覧の変更と `scripts` 等の CI が読む部分の変更を分けて扱っている
- 検証器が、変更されたキー (例: `dependencies` / `devDependencies` と `scripts`) を構造として比べて判定するか、CI が読む設定を混在ファイルの外 (開発コマンドの入口、独立した設定ファイル等) に移してファイル単位の保護が効くようにするか、少なくともどちらかの手段がある
- 承認が要る変更と承認なしで通してよい変更を同じ PR に混ぜない (分けて出す) 旨がある
- CI やルールを緩める変更 (`scripts` の変更等) は承認が要る扱いのまま残っている
