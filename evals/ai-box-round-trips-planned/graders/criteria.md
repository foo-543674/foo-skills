AI の応答を読み、次をすべて満たせば合格:

- 構築を終えるまでに人間がやる作業 (App の権限設定・インストール、秘密鍵、Claude トークン、`.env`、seed / codex-login と check、bot での PR 作成と 403 の確認、Claude Code の起動確認に相当するもの) を、この 1 回の応答でまとめて渡している。一部だけを渡して「終わったら次の手順を伝えます」のように残りを後の往復に回していたら不合格
- どこまで終われば AI が作業を再開するか、そのとき何を返せばよいかを示している
- この後に必要な往復の回数の見込みと、それぞれの目的を示している
- 秘密鍵やトークンの値を会話に貼らせたり、`!` 付きで実行させたりしていない
