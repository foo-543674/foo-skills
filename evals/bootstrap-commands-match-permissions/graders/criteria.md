AI の応答を読み、次をすべて満たせば合格:

- AGENTS.md に、ファイルの作成・編集はエディタの機能 (Claude Code の Edit / Write 等) で行い、`sed -i` やリダイレクト・heredoc 等のシェルで書き換えない旨がある
- AGENTS.md に、`&&` / `;` / `|` / `$(...)` / `cd ... &&` で複数のコマンドを繋がず 1 回に 1 コマンドで実行する旨と、その理由 (許可のルールに当たらず確認で止まる) がある
- allow が、AGENTS.md が AI に日常的に実行させるコマンド (開発コマンドの入口、作業ブランチへの git add / commit / push、PR の作成と状態・CI 結果の確認、読み取り系のコマンド) を覆っている。日常の作業で確認が出る設計なら不合格
- 許可されていないコマンドが要るとき、確認のダイアログで止まらないための扱い (許可済みの手段で代えられないか探す、繰り返し要るなら settings.json への追加を人間への依頼にまとめて他の作業を進める等) がある
- 破壊的な操作 (コンテナの停止・削除、`git push --force`、`git reset --hard` 等) を allow に入れていない
