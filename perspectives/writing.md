# Writing

文書の書き方に関する品質レンズ。書く前には「この文書を何のために誰に書くか」を固定するために、読み返すときには「読み手がこの文書で判断・行動できるか」を評価するために使う。対象は設計文書・PRの説明・判断依頼・報告・手順書など、人が読む文書のすべて。

## この観点で重視すること

- **書く前に3つを固定する**: 読み手（誰が読むか。使ってよい語・扱ってよい情報の範囲）、目的（読み手がこの文書で何を判断・行動するかを一文で）、媒体（読み手がどんな状態で出会うか。通知で一行だけ見る、会議で画面共有する、作業の途中で検索して開く）。手元の素材から書き始めると、素材の順に並んだ文書になる
- **読み手が判断・行動する順に組む**: 読み手に求めること（依頼・問い・結論）を冒頭に置き、背景はその材料として後に続ける
- **言明の確度を読み手に見せる**: 読み手は、どこまでを前提にしてよいかを確度で決める。確度の見えない文書は、全部を疑うか全部を信じるかの二択を読み手に強いる

## 判断基準

### 確度

- 言明を4つに分ける: 裏取り済みの事実／決定済み／未決／提案。未決と提案は本文に明記する。4つのどれか指せない言明は書かない
- 未決には、誰がどの場で決めるかと、温度感（決まるまで止まる／答え次第で後が変わる／知っておけばよい）を添える
- 依頼者の言明は、条件・程度・見立てを保ったまま書く。「〜なら」「たぶん」「今のところ」を落として決定に格上げしない

### 構成

- 仕組みを扱う文書は、動いているとき・壊れたとき・日々の運用・変えるときの全場面で、誰が何をするかを並べる。動いているときだけの説明は、壊れたときに読み手を置き去りにする
- 文書の寿命と主題に合うものだけを書く。先に変わるもの（進捗・時期・担当・現在の範囲）は、寿命の短い文書（Issue・PR・作業記録）に置く
- 3つ以上並ぶものは表か1項目1行にする

### 語

- 語は、読み手がその場面で普段使う語にそろえる。読み手に定着した語をわざわざ訳した日本語も、読み手に通じないカタカナ語も、読み手にとっては造語である。置き換えは注釈でなく言い換えで行う
- 略語は初出で正式名称と何を指すかを添える
- 用語は役割から説明する: 何を守る・解決するために、誰がいつ使うものか
- 呼称は冒頭で固定し、同じものを同じ語で呼ぶ。一覧の番号は索引であって呼称ではないので、離れた箇所で指すときは名前を添える
- 日付は絶対表記で書く（「来週」「先月」は読む日によって指す日が変わる）
- 日本語と半角英数字の境界に半角スペースを入れない。コード・URL・英単語どうしの間は対象外

### 載せるもの

- 「秘密か」と「載せるか」は別に判定する。秘密でなくても、読み手の判断を変えないものは載せない
- 書き手の規範（AI向けの制約・作業上の注意）は書き手の側に置き、読み手の文書には読み手が使う内容だけを書く
- 直させた内容は、直した後の形を肯定形で書く

### 図

- 同じ種類の矢印は束ねる。矢印は直線で引ける配置にし、描いたらプレビューで確かめる
- 既存の図があれば下敷きにする
- 技術者向けの図の合格基準は「そのまま詳細設計に入れるか」

## アンチパターン

- **Background First**: 背景・経緯から書き始め、読み手に求めることが末尾に埋もれる
- **Padding**: 自明な主語、回りくどい枠（「〜について説明します」）、同じ定義の繰り返し
- **Poem**: 理念の宣言から入る導入、比喩で仕組みを説明する
- **Negative Residue**: 直させた内容を「〜しない」の否定形で残す。読み手には何をすればよいかが残らず、否定された形を逆に覚えさせる
- **Process Leak**: メタ情報・調査の過程・作業の経緯を本文に残す（「調べたところ」「当初は〜と考えたが」）
- **Scattered Questions**: 読み手への問いかけを本文の各所に散らし、何に答えればよいかを読み手に探させる
- **Promoted Statement**: 依頼者の「たぶん」「今のところ」を落とし、見立てを決定として書く
- **Coined Label**: 読み手が普段使わない語を、定義なしに見出しや状態名に使う

## 品質チェックポイント

提出前の自己監査として使う。

- [ ] 各数値・事実・用語に出所があり、自分で裏取り・再計算したか。「無い」という言明も、記録を横断検索した結果として書いたか
- [ ] 絞り込みや枠組みを使ったとき、その導出過程を見せたか
- [ ] 評価軸をまたぐ判断（速さと安全、費用と品質など）を明示したか
- [ ] 「要確認」で済ませず、調べて分かることは調べ切ったか
- [ ] 曖昧なラベルを、何が起きるかの具体的な記述にしたか
- [ ] 呼称を冒頭で固定し、最後まで同じ語で呼んだか
- [ ] 読み手の普段の語で書き、略語に正式名称を添えたか
- [ ] 読み手の目的に無関係な要素を除いたか
- [ ] 直させた内容を否定形で残さず、同じ判断で書いた他の箇所も洗い直したか
- [ ] 目的と媒体に合った文体か
- [ ] 読み手に合わない専門用語を言い換えたか
- [ ] 未決と提案が本文に明記され、未決に決める人・場・温度感があるか
